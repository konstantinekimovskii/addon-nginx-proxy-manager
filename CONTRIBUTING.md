# Contributing

This fork is no longer maintained and does not accept new contributions.

Please report issues and submit pull requests to the actively maintained
original project:

- Project: <https://github.com/hassio-addons/app-nginx-proxy-manager>
- [Contribution guidelines](https://github.com/hassio-addons/app-nginx-proxy-manager/blob/main/.github/CONTRIBUTING.md)

Do not report security vulnerabilities in this unmaintained fork's public
channels. For the maintained version, follow the original project's security
policy.
